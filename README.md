# RandomGroupAssigner

A small vibe-coded program to randomly assign students to groups

Made with codex.

# Prompt

Erzeuge ein einfaches Programm mit benutzerfreundlichem Interface, in das ich Namen von Studierenden eingeben kann und mit einem Knopfdruck werden zufällig Paare gebildet. Zweck ist zufällige Gruppeneinteilung für Teamarbeit. Man sollte auch die Gruppengröße bestimmen können. Wenn die eingegeben Gruppengröße wegen der Anzahl der Studierenden nicht aufgeht, ist es ok, eine minimale Anzahl an größeren Gruppen zu haben.

Ausgabe = HTML, Tailwind CSS, Javascript in einem lokalen Ordner.

Ziel = Möglichst einfacher Code, möglichst wenig LOC
